Album Visual Strategy · Executive Summary

2026 专辑视觉照片采集策略

我们要找的不是专辑封面，而是能让读者一眼理解专辑气质的视觉照片： 概念照、宣传照、teaser visual、MV still、媒体首发视觉等。

当前核心判断

不能用一个渠道解决所有专辑。正确路线是先判断专辑类型，再走对应的视觉采集 playbook。

一句话结论

现在不是继续盲目加渠道，而是建立“类型分流 + 图片分层 + 人工复核”的机制。 K-pop、欧美主流 pop、粉丝 Wiki 强艺人、电影/视觉宇宙型专辑、独立厂牌专辑，视觉资料出现的位置完全不同。

老板需要知道的重点

当前网页已经能展示一批高质量视觉资料，但自动化扩大召回后会混入封面、官网小图、review 配图。 所以下一步不是把 v7 的 49 张候选全部上线，而是把候选池做清洗，确保老板 review 时看到的是“专辑视觉概貌”，不是资料噪音。

什么算视觉照片

我们把图片分层，避免把“有图”误判成“有视觉”。封面和站点缩略图只能兜底，不能证明专辑有视觉概念。

01

Confirmed Visual

概念照、photoshoot、宣传照、MV still，页面语义和图片内容都强相关。

02

Candidate Visual

可能属于专辑周期，但需要人工看一眼，例如媒体配图、官方视频缩略图。

03

Cover / Artwork Only

专辑封面、单曲 artwork、实体商品图，不计入核心视觉覆盖。

04

Reject

站点 logo、小图、share image、旧 era、无关推荐视频，直接剔除。

按专辑类型分流

最有效的策略不是“搜专辑名”，而是先判断专辑属于哪类，再决定去哪里找图。

专辑类型 视觉资料通常在哪 优先渠道 风险控制
K-pop idol comeback 概念照、teaser、成员图通常成套发布 Kpopping、Kpop Wiki / Fandom、KpopOfficial Kpopping 优先；Fandom 做补充，避免混入旧单曲页
粉丝 Wiki 强艺人 专辑 Gallery、Photoshoot、Promotional Material 艺人 Fandom 子域、MediaWiki API 只信专辑 Gallery；song page 默认降级
欧美主流 pop campaign 专辑采访、公告、单曲 MV、媒体首发页、press photo Brave 定向搜索、Vogue / NME / Promonews / Dork / Uproxx、官方视频 必须确认 album-era single；媒体 og:image 不能直接算核心视觉
Album-film / transmedia 官方视频、电影剧照、press release、first-look photos 官网、厂牌 press release、媒体剧照、官方 YouTube、Fandom API 过滤封面、alternate cover、playlist、Topic audio
独立 / 厂牌导向专辑 厂牌官网、Bandcamp、press release，通常图少 官方站、厂牌页、Bandcamp、Google CSE 如果只有封面，不强行凑视觉覆盖
Live / archive / reissue 多为旧录音、现场档案、再版封面 默认降级或跳过 没有新视觉 campaign 时，不消耗抓取预算

渠道优先级

官方来源最可信，但并不总是最完整；专业图库和粉丝 Wiki 召回强，但必须复核版权和页面类型。

核心渠道

官方 / 厂牌 / press kit Kpopping Fandom Gallery 媒体首发页 官方视频

  • 官方来源质量最高，但很多专辑官网只放封面。
  • Kpopping 对 K-pop 概念照最有效，单张专辑可抓满 9 张。
  • 欧美主流 pop 要沿 album-era singles 找媒体图和 MV still。

辅助与兜底

小红书候选 Cover Art Archive Google CSE YouTube Data API

  • 小红书只作为中文语境线索，不计入核心覆盖。
  • Cover Art Archive 是封面库，只做封面兜底。
  • Google CSE / YouTube API 适合后续补官方站和视频能力。

当前进展与风险

v7 证明 press campaign 路线能大幅提升召回，但也暴露出质量问题：自动抓到的图不一定都是视觉照片。

好消息

  • Top 80 原始候选覆盖从 21 张提升到 49 张。
  • 新增候选主要来自媒体页、官网图片、官方视频缩略图。
  • RAYE、Olivia Dean、The Weeknd、aespa、Poppy 等 case 已验证多条有效路径。

不能直接上线的原因

  • 36 个抽检 / 新增 / 可疑条目中，29 个被标记风险。
  • 常见误收包括封面、方形 packshot、小图、站点 share image、review metadata 图。
  • Brave 搜索配额触达限制后，v8 加严版还没跑完。

下一步建议

下一步目标是把“候选池”变成“可给老板 review 的视觉板”。优先做质量门槛，而不是继续堆渠道。

Step 1

建立黄金评测集

从 Top 80 中选 20 张成功、失败、边界案例，每次改策略都用它验证准确率。

Step 2

跑 v8 加严版

配额恢复后，用页面语义、图片尺寸、来源类型过滤 v7 噪音。

Step 3

人工 review 候选池

对 contact sheet 做快速审核，只把 confirmed / high-confidence candidate 上线。

Step 4

产品化采集流程

加搜索缓存、来源缓存、负样本规则，降低请求消耗和结果波动。
