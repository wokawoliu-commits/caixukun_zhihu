# 学生社交伴手礼市场深度调研

This directory is a static deployment bundle for the research report.

## Files

- `index.html`: main web report
- `report.pdf`: PDF version of the report
- `data/student_social_gifts_research_data_20260612.xlsx`: workbook with research tables
- `data/product_samples.csv`: Taobao/Tmall product samples
- `data/xhs_notes.csv`: anonymized Xiaohongshu sample table
- `data/opportunity_map.csv`: opportunity map
- `data/product_category_summary.csv`: product category summary
- `data/quadrant_summary.csv`: four-quadrant summary
- `data/product_sample_summary.json`: product sample aggregate summary

## Deploy

Use this folder as the static site root. No build step is required.
