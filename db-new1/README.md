## 可信度等级

- A：官方/本人/品牌/平台/主办方，如 Apple Music、MIKIMOTO 官网、爱奇艺、央视网、腾讯视频相关官方信息。
- B：主流媒体、长采访、节目正片、行业媒体，如 人民网、新京报、SCMP、新浪财经/时尚。
- C：粉丝站、超话、街拍账号、粉丝整理表、社区讨论；只能作为线索或补充观察。

## 使用原则

- 正文只写可追溯的公开资料；隐私、恋情传闻、无法追溯八卦不纳入。
- 性格类结论统一写成“基于公开资料可观察到”，避免绝对化判断。
- 私服资料只记录公开发布的图片、活动和场景，不记录实时行程、酒店、航班等敏感信息。
- 作品、代言、奖项三类均按年份建立索引，方便后续月更。
- 粉丝资料必须标 C 级，不与官方事实混写。

## 月更节奏

每月更新一次，重点检查：

- 新作品：官宣、开机、杀青、定档、播出、平台成绩。
- 新商务：品牌官宣、title 升级、合作结束、线下活动。
- 新荣誉：奖项、提名、时尚榜单、公益荣誉。
- 新采访：补充性格、自我认知、职业规划。
- 新公开造型：红毯、杂志、品牌活动、公开私服。

## 当前限制

本首版以公开网页资料为基础，未登录微博、豆瓣、超话、品牌小程序或粉丝私域；因此部分微博官宣、街拍单品、商务有效期需要二次核验。所有此类内容已在对应文件标注“待复核”或 C 级来源。
