# Design system

## Editorial character

报告与拍摄共享“动作留下痕迹”的视觉语法：锐利编辑排版、留白、细线、纸张感和五个章节色，不使用渐变、拟物大圆角或娱乐榜单式信息堆叠。

## Five-chapter palette

| Chapter | Color | Use |
|---|---|---|
| BREATHE | Ivory / fog blue | 未开始的光、定位线 |
| MOVE | Glacier blue / silver gray | 身体路径、炭线 |
| NOTICE | Mist green / oat | 窗、风、生活感 |
| CHOOSE | Plum / wine / rose brown | 主动选择与光框 |
| SHARE | Smoky lilac / liquid silver | 舞台与共享完成 |

## Typography and layout

- 中文正文优先系统无衬线，标题可使用有编辑感的中等字重；英文动词全大写并增加字距。
- 页面最大阅读宽度约820像素，表格允许横向滚动。
- 标题、章节和证据之间用细线分隔；不使用装饰性emoji。
- 所有色彩对比须满足正文可读性，移动端保持单栏。
